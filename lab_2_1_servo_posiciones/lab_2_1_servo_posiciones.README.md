# lab_2_1_servo_posiciones.ino

Real-time servo control via potentiometer with LCD display and 4-position memory recording.

**Key Features:** Analog read, smoothing (8 samples), 2° threshold, position recording/playback, I2C LCD.

**Pins:** Pot (A0), Servo (10), Button (22), LCD (SDA/SCL 20/21).

**Modes:** Manual control, record positions, replay sequence.

**Board:** Arduino UNO | **Baud:** N/A
