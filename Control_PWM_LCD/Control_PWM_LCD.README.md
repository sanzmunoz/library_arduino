# Control_PWM_LCD.ino

4-stage motor speed control via pushbuttons with LCD display and status LEDs.

**Key Features:** Gradual acceleration, stage indicators, 25%-100% PWM range, anti-debounce.

**Pins:** Motor (9,24,25), Buttons (50-53,46,47), LEDs (40-43), LCD (SDA/SCL 20/21).

**Flow:** Start → Select Stage → Smooth Ramp → Stop.

**Board:** Arduino Mega 2560 | **Baud:** N/A
