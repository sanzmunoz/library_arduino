# LCD_Servo_T4x4_v2.ino

Enhanced version of LCD_Servo_T4x4. Improved menu system, adjustable speed, sequence recording/playback.

**Key Features:** Menu navigation, position presets, motion sequences, better error handling, optimized code.

**Pins:** Keypad Rows (9,8,7,6), Columns (5,4,3,2), Servo (3), LCD (SDA/SCL 20/21).

**Modes:** Manual, Presets, Record, Playback.

**Board:** Arduino UNO | **Version:** 2
