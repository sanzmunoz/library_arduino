# Servo_Pot_Con_respuestas.ino

Quiz solution: Potentiometer-controlled servo with full explanation and circuit diagrams.

**Key Features:** Analog mapping (0-1023 → 0-180°), noise filtering, serial output, complete documentation.

**Pins:** Pot (A0), Servo (9).

**Usage:** Rotate potentiometer to control servo position in real-time.

**Board:** Arduino UNO | **Type:** Graded Exercise
