# Teclado4x4_E2.ino

Exercise 2: Enhanced keypad functionality with command processing and LCD feedback.

**Key Features:** Keypad input parsing, command recognition, LCD output formatting, extended functionality.

**Pins:** Keypad Rows (9,8,7,6), Columns (5,4,3,2), LCD (SDA/SCL A4/A5 or 20/21).

**Enhancement:** Process key sequences into commands.

**Board:** Arduino UNO | **Type:** Learning Exercise 2
