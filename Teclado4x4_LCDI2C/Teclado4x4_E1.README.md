# Teclado4x4_E1.ino

Exercise 1: Basic 4×4 keypad capture and display on LCD. Shows pressed keys and auto-resets after 8 characters.

**Key Features:** Keypad library, I2C LCD, character buffering, auto-clear cycle.

**Pins:** Keypad Rows (9,8,7,6), Columns (5,4,3,2), LCD (SDA/SCL A4/A5 or 20/21).

**Flow:** Capture → Display → Auto-reset.

**Board:** Arduino UNO | **Type:** Learning Exercise 1
