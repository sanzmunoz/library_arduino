# Laboratorio_1.ino

Educational binary-to-decimal converter. Reads 4 digital inputs, reflects to outputs, calculates decimal value via bitwise operations.

**Key Features:** Array-based I/O, bitwise shift operators, serial reporting, loop optimization, anti-debounce.

**Pins:** Inputs (22-25), Outputs (26-29), Button (30).

**Formula:** Decimal = Σ(bit_i × 2^i).

**Board:** Arduino Mega 2560 | **Baud:** 9600
