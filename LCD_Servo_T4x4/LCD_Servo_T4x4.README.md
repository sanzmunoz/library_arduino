# LCD_Servo_T4x4.ino

Servo control via 4×4 keypad with LCD feedback. Preset angles mapped to keypad buttons.

**Key Features:** Keypad library, I2C LCD, angle mapping (1→20°, 2→45°, etc.), real-time display.

**Pins:** Keypad Rows (9,8,7,6), Columns (5,4,3,2), Servo (3), LCD (SDA/SCL 20/21).

**Keypad Map:** [1-5] for angles, [A] for center, [D] for reset.

**Board:** Arduino UNO | **Baud:** N/A
