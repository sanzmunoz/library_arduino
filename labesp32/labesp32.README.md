# labesp32.ino

Wireless DC motor control via Bluetooth (ESP32). Commands: F (forward), B (backward), S (stop), V (velocity 0-255).

**Key Features:** BluetoothSerial, L298N driver, PWM 5kHz, command parsing, real-time velocity adjust.

**Pins:** Motor IN1 (26), IN2 (27), ENA (25).

**Device Name:** ESP32_ControlMotor_PWM | **Baud:** 115200

**Board:** ESP32
