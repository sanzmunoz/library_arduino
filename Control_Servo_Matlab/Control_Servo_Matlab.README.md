# Control_Servo_Matlab.ino

Servo motor control via MATLAB serial commands. Receives angle values (0-180°) and generates PWM pulses.

**Key Features:** Serial read/parse, PWM servo generation, angle feedback, detailed PWM explanation.

**Pins:** Servo Signal (9).

**Protocol:** MATLAB sends angle → Arduino positions servo.

**Board:** Arduino UNO | **Baud:** 9600
